# REQ-001: Filesystem Tools

## Overview

The system must provide 9 core filesystem operation tools accessible via MCP protocol.

## Functional Requirements

### Tool Set

1. **fs_read_file**: Read file content with size limit (10MB default)
   - Input: `path` (string)
   - Output: File content as string
   - Validation: File size < limit, path within sandbox

2. **fs_write_file**: Create or overwrite file with content
   - Input: `path` (string), `content` (string)
   - Output: Confirmation message with bytes written
   - Validation: Path within sandbox, confirmation for large overwrites

3. **fs_list_directory**: List directory contents with metadata
   - Input: `path` (string), `recursive` (bool, optional)
   - Output: List of FileInfo objects
   - Validation: Directory exists and is readable

4. **fs_create_directory**: Create directory including intermediate directories
   - Input: `path` (string)
   - Output: Confirmation message
   - Validation: Path within sandbox, idempotent operation

5. **fs_delete**: Delete file or directory
   - Input: `path` (string), `force` (bool, optional)
   - Output: Confirmation message
   - Validation: Confirmation required for non-empty directories

6. **fs_move**: Move or rename file/directory
   - Input: `source` (string), `destination` (string)
   - Output: Confirmation message
   - Validation: Both paths within sandbox, confirmation for overwrites

7. **fs_copy**: Copy file or directory
   - Input: `source` (string), `destination` (string), `recursive` (bool)
   - Output: Confirmation message with bytes copied
   - Validation: Paths within sandbox

8. **fs_search**: Search files by glob pattern or content match
   - Input: `pattern` (string), `path` (string), `content_match` (string, optional)
   - Output: List of SearchMatch objects
   - Validation: Max 1000 results, 30-second timeout

9. **fs_file_info**: Get detailed file metadata
   - Input: `path` (string)
   - Output: FileInfo object with size, permissions, timestamps
   - Validation: File exists and is readable

## Non-Functional Requirements

### Performance
- Tool execution latency < 100ms (p95) for operations under 1MB
- Search tool completes within 30 seconds or returns partial results

### Security
- All paths validated against ALLOWED_PATHS sandbox
- Path traversal attempts (../) rejected
- Destructive operations logged to audit trail

### Reliability
- All tools return structured ToolResult with success flag
- Execution time measured for all operations
- Errors include actionable error messages

## Testing Requirements

### Unit Tests
- Each tool tested in isolation
- Validation logic tested with adversarial inputs
- Error conditions tested (file not found, permission denied)

### Integration Tests
- Multi-tool workflows (search → read → write)
- Large file handling (up to size limit)
- Directory recursion (up to max depth)

### Security Tests
- Path traversal attempts blocked
- Symlink exploitation prevented
- Confirmation prompts trigger correctly
