# REQ-002: Agent Loop (ReAct Pattern)

> **Superata (2026-08-16).** Requisito non implementato: vedi [ARC-002](../architecture/ARC-002.closure-decision.md) e lo [spike sui guardrail MCP](../09-SPIKE-MCP-GUARDRAILS.md).

## Overview

Implement autonomous agent loop with planning, execution, observation, and reflection stages.

## Functional Requirements

### Agent Loop Stages

1. **USER_INPUT**: Receive natural language query
2. **PLANNING**: Ollama analyzes task and decides if tool needed
3. **TOOL_CALL**: Parse JSON tool request and validate arguments
4. **EXECUTION**: Execute MCP tool with timeout
5. **OBSERVATION**: Insert tool result into conversation context
6. **REFLECTION**: Ollama evaluates if task completed
7. **LOOP**: Return to PLANNING if not completed (max 10 iterations)
8. **RESPONSE**: Generate final natural language answer

### Loop Control

- Maximum iterations: Configurable (default: 10)
- Early termination: When LLM indicates completion
- Error handling: Failed tools don't terminate loop
- Context management: Full message history maintained

## Non-Functional Requirements

### Performance
- 1-step query (read only): < 2s total time
- 3-step query: < 5s total time
- 5-step query: < 10s total time

### Reliability
- Graceful degradation on tool failures
- Partial results returned if max iterations exceeded
- No infinite loops (hard limit enforced)
