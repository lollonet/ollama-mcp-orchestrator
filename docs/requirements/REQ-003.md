# REQ-003: CLI Interface

## Overview

Provide Typer-based CLI with interactive chat mode, single-query mode, and configuration management.

## Functional Requirements

### Commands

```bash
ollama-fs chat              # Interactive REPL mode
ollama-fs ask "query"       # Single query mode
ollama-fs --model NAME      # Override default model
ollama-fs --verbose         # Enable debug logging
ollama-fs config show       # Display current configuration
ollama-fs config set KEY VAL # Update configuration value
```

### Interactive Features (Chat Mode)

- REPL with prompt: `You: `
- Commands: `/help`, `/history`, `/clear`, `/exit`
- Rich formatting: banners, tables, progress bars
- Confirmation prompts for destructive operations

### Output Formatting

- Human-readable by default
- `--json` flag for structured output
- Color-coded messages (info, warning, error)
- Tool execution details in verbose mode

## Non-Functional Requirements

### Usability
- First-time user can complete task in < 5 minutes
- Help text accessible via `--help` at every level
- Clear error messages with remediation steps
