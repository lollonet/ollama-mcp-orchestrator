# REQ-004: Security Sandbox

> **Superata (2026-08-16).** Requisito non implementato: vedi [ARC-002](../architecture/ARC-002.closure-decision.md) e lo [spike sui guardrail MCP](../09-SPIKE-MCP-GUARDRAILS.md).

## Overview

Enforce path-based security sandbox to prevent unauthorized filesystem access.

## Functional Requirements

### Path Validation

- **ALLOWED_PATHS**: Configurable list of allowed base paths (default: `~/projects`)
- **Path Resolution**: Resolve all paths with `Path.resolve()` before access
- **Traversal Prevention**: Reject paths containing `..` or absolute paths outside sandbox
- **Symlink Resolution**: Follow symlinks and validate final destination

### Confirmation Prompts

User confirmation required for:
- Deleting non-empty directories
- Overwriting existing files > 1MB
- Moving/copying > 100 files

### Audit Logging

All security events logged:
- Path validation failures
- Confirmation prompt results
- Successful/failed access attempts

## Non-Functional Requirements

### Security
- Zero false positives (valid paths not rejected)
- Zero false negatives (invalid paths not allowed)
- Comprehensive test coverage for attack vectors
