# REQ-006: Ollama Integration

## Overview

Integrate with Ollama Python client for LLM inference with retry logic and model verification.

## Functional Requirements

### Supported Models
- Qwen2.5:32b (default, recommended for speed)
- Llama3.3:70b (high quality, requires 42GB RAM)
- Qwen3-coder:30b (coding-optimized)

### Client Features
- Chat API with function calling support
- Retry with exponential backoff (3 attempts)
- Model availability check on initialization
- System prompt injection
